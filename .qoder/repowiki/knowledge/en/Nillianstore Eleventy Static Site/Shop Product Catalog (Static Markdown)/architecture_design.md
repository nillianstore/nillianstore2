Flat content store consumed by Eleventy: each product is a single `.md` file named by its Amazon `ecwidId` (e.g. `B0CLHGCYRN.md`) sitting directly under `shop/`, plus a root `shop.json` that tags the collection as `shops`. Front matter fields (`title`, `description`, `price`, `cover`, `images`, `ecwidId`, `category`, `tags`, `layout`, `amazonLink`, `permalink`, `date`, `bullet_points`, `cover_alt`, `image_alts`) are rendered via the shared `layouts/shop.njk` template referenced in every page's front matter. There is no application code — this module is purely data + templates, with images expected at `/img/<id>.webp` alongside their variants.

The root is an Eleventy project whose `.eleventy.js` configures the shared build pipeline consumed by every child: it registers plugins (RSS, syntax highlight, navigation), defines global data (`site.url`), layout aliases (`post`, `shop`), filters (`readableDate`, `htmlDateString`, `isoDateTime`, `safeSlug`, `filterTagList`, `sanitize`, `xmlEncode`), collections (`tagList`), passthrough copies (`img`, `css`, `feed`, `videos`), and a custom markdown-it library with anchor links. All children are addressed via Eleventy's directory conventions — `content_pages/` and `blog_posts/` supply Markdown input pages, `shop_products/` supplies product pages, `site_templates/` provides Nunjucks layouts/widgets under `_includes`, `feed_generation/` emits Atom/JSON Feed and catalog outputs, and `build_scripts/` plus `ci_cd/` drive pre/post-build automation (Groq post generation, social publishing, filename checks). The CI workflows invoke the same `npm run build` / `eleventy` commands declared in `package.json`, so the root config is the single contract binding content, templates, generators, and deployment.

Four Eleventy data/templating files in `feed/`, each using a YAML front-matter block to declare its output via `permalink` and to opt out of collection indexing with `eleventyExcludeFromCollections: true`. `feed.xml.njk` renders an Atom feed over both `collections.posts` and `collections.shop`; `json.njk` renders a JSON Feed v1.1 whose path is driven by `metadata.jsonfeed.path`; `products.json.njk` emits a flat `/products.json` catalog; `htaccess.njk` produces a `.htaccess` file under `feed/` that sets `DirectoryIndex` to `{{ metadata.feed.filename }}` so browsing the directory serves the chosen feed. All templates consume shared site context (`site.url`, `metadata.*`) and post/shop item data (`item.data.title`, `item.data.description`, `item.data.cover`, `item.data.price`, `item.data.ecwidId`, `item.data.amazonLink`, `item.date`).

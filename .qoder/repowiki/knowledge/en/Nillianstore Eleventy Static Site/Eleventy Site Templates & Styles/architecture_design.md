Templates are organized into three cooperating directories consumed by Eleventy:
- `_includes/layouts/` defines page-level layout wrappers (`base.njk`, `home.njk`, `page.njk`, `post.njk`, `shop.njk`) that declare a `layout:` front-matter and render `{{ content | safe }}`. `base.njk` is the root shell, assembling `widget/head`, `navbar`, `content`, and `footer`.
- `_includes/widget/` holds reusable fragments (`head.njk`, `navbar.njk`, `content.njk`, `footer.njk`, `seo.njk`, `script.njk`, `sitemap.njk`, `tag.njk`, `contact.njk`) — every HTML document starts with `widget/head.njk`, which opens `<html>`/`<head>`/`<body>` and inlines critical CSS via `rel=preload` + `onload`, defers Swiper and Bootstrap JS, and injects Google Analytics / EmbedSocial scripts conditionally.
- `_includes/desain/` contains theme-specific overrides grouped by feature area (`blog/`, `shop/`, `contact/`, `home/`, `page/`, `404/`) plus a variant layer (`themes/free.njk`, `pro.njk`, `support.njk`, `template.njk`). `desain/themes/template.njk` composes the three variants; each variant file re-includes its own `control.njk`, `head.njk`, `slider.njk`, etc., allowing free/pro/premier themes to share structure while overriding per-section includes.
- Top-level list templates (`pageslist.njk`, `postslist.njk`, `shopslist.njk`, `tagslist.njk`) render collection feeds and are included from page layouts.
- `css/` holds two stylesheets: `bs.css` (Bootstrap overrides) and `index.css` (responsive image/video rules); both are preloaded from `widget/head.njk` via the `url` filter.

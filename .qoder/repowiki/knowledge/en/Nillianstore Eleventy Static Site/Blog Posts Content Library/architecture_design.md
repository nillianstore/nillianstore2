Flat content directory consumed by the Eleventy static-site generator. Each `.md` file is an independent post using YAML front matter (`title`, `description`, `cover`, `date`, `tags`, `layout: layouts/post.njk`, `permalink`) so Eleventy renders it via the shared Nunjucks layout. A single `posts.json` at the root declares the collection tag `posts`, which is how Eleventy discovers this folder as a content collection. There is no code — only authored articles, one per product or theme (gift guides, padel accessories, night lights, teapots, ceramics, fishing hooks), linked out to `amazon.ae/dp/...` product pages.

# Nillianstore

**[https://www.nillianstore.com](https://www.nillianstore.com)** — a static product-showcase website for the **Nillianstore Amazon.ae seller account** ([Amazon storefront](https://www.amazon.ae/s?me=A20X6G0BNN7WDJ&marketplaceID=A2VIGQ35RCS4UG)).

Handpicked home decor, tea accessories, kids' lighting, and lifestyle products for UAE homes (Dubai, Abu Dhabi, Sharjah) — curated, priced in AED, and every product links out to **Buy on Amazon.ae**. There is no cart or checkout here: the site exists for discovery, SEO, and driving traffic to the Amazon storefront.

Built on [Eleventy (11ty)](https://www.11ty.dev) — markdown in, static HTML out — and deployed to **Netlify**.

## How it works

- **Products** live in `shop/` as one markdown file per Amazon ASIN (e.g. `shop/B0CLHGCYRN.md`). Frontmatter carries the title, description, AED price, category, tags, product images, and the `amazonLink`; the body is the product description.
- **Blog posts** in `posts/` are SEO content per product — hand-written or auto-generated by the blog bot — each embedding a "Buy on Amazon.ae" button.
- **Site identity** (schema.org business data, social links, feed metadata) lives in `_data/metadata.json`; hero copy in `_data/home.json`.

## Quick start (local)

```bash
npm install            # Eleventy + plugins + sharp
npm run serve          # build + live reload (http://localhost:8080)
npm run build          # optimize images (sharp) then build into _site/
npm run check:filenames   # CI guard: no ? / # in generated filenames
```

CI uses Node 18 (`.nvmrc`); local Node 18+ works fine.

## Repository layout

| Path | What it is |
|---|---|
| `shop/*.md` | One file per Amazon ASIN — the product catalog (frontmatter + description) |
| `posts/*.md` | SEO blog posts (hand-written + bot-generated) |
| `page/*.md` | Static pages: about, contact, sourcecode, policies |
| `_data/` | Site metadata (`metadata.json`), home hero (`home.json`), widget copy |
| `_includes/` | Live Nunjucks templates (`layouts/`, `home.njk`, `seo.njk`, `sitemap.xml.njk`, …) |
| `_includes/desain/` | **Template legacy** from the original 11tyshop starter — mostly unused, don't chase bugs there |
| `img/` | Product images (`B0<ASIN>.webp` + `-1…-4` gallery); optimized by `scripts/optimize-images.js` |
| `scripts/` | Build helpers: image optimization, filename validation, bot test runner |
| `blog_bot.py` / `social_bot.py` | Groq / Meta automation — run by GitHub Actions, not locally |
| `.github/workflows/` | Build check, site validation, blog bot (weekly), social bot (every 8h) |
| `blog_log.json` / `social_log.json` | Bot rotation history (which ASINs were already blogged / posted) |

## Adding a product

1. Drop product images into `img/`: cover `B0<ASIN>.webp`, gallery `B0<ASIN>-1.webp` … `B0<ASIN>-4.webp`.
2. Create `shop/B0<ASIN>.md`, modeled on an existing file — frontmatter: `title`, `description`, `price` (AED), `cover`, `images`, `category`, `tags`, `amazonLink`, `permalink: /shop/b0<asin>/`, plus alt texts; body = full product description.
3. Run `npm run build` — the shop listing, sitemap, and product JSON pick it up automatically.
4. Optional: let the bots promote it (weekly blog post, 8-hourly Instagram/Facebook posts), or write a blog post in `posts/` by hand.

Filenames must stay URL-safe (no `?` or `#`) — `check-filenames.js` enforces this in CI.

## Automation

### Blog bot — `.github/workflows/blog_bot.yml` (weekly, Sundays 00:00)
`blog_bot.py` picks a product not yet blogged (rotation tracked in `blog_log.json`), has Groq (Llama 3.3 70B) write an SEO post with UAE context, validates the Eleventy build, and commits the new post back to `posts/`.
Secrets: `GROQ_API_KEY`.

### Social bot — `.github/workflows/social_bot.yml` (every 8 hours)
`social_bot.py` picks one product, generates a caption + hashtags with Groq, and posts it to **Instagram** (carousel, up to 10 images) and **Facebook** (photo) via Meta Graph API v18. It dedupes via `social_log.json` (last 50 ASINs) and pushes the log back to the repo. Retries up to 3 times with different products on failure.
Secrets: `GROQ_API_KEY`, `META_ACCESS_TOKEN`, `FB_PAGE_ID`, `IG_USER_ID` — see [SOCIAL_BOT_SETUP.md](SOCIAL_BOT_SETUP.md). The recurring failure mode is an expired Meta token (Graph error code 190) → refresh it in the Facebook Developer Console and update the GitHub secret.

### Build & validation
- `build-check.yml` — plain Eleventy build on push/PR.
- `validate-site.yml` — full `npm run build` (includes the sharp image-optimization pass) + the filename check.

## Useful scripts

- `scripts/optimize-images.js` — sharp resize/re-encode of `img/` (gallery ≤800px, covers ≤1200px, webp q80). Runs as part of `npm run build`.
- `scripts/check-filenames.js` — fails the build if any generated filename contains `?` or `#` (Netlify rejects these).
- `verify_links.py` — checks every blog post's Amazon button matches its product's `amazonLink` in `shop/` (needs `pip install python-frontmatter`).
- `test_frontmatter.py`, `scripts/test_blog_bot_run.py` — local sanity checks for the bot pipelines.

## Deployment

Netlify: `netlify.toml` sets `command = "DEBUG=* eleventy"` and `publish = "_site"`. Push to `main` → CI validates → Netlify deploys.
